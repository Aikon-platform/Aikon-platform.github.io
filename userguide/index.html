User Documentation

AIKON is a modular platform designed to support historians working with visual materials. It provides tools for building document corpora, applying computer vision algorithms, and analyzing results through dedicated interfaces.

Platform Workflow

AIKON guides users through three interconnected phases: corpus construction, targeted processing, and results validation. Each phase is designed to maintain researcher control over automated outputs.

Corpus Constitution

Create and organize your document corpus using the platform's data model.

Document Processing

Apply computer vision algorithms to extract regions, compute similarities, and vectorize diagram.

Analysis & Interpretation

Explore results through visualization tools and examine transmission networks across your corpus.
